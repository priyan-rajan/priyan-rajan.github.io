# Priyanka Rajan's Personal Website

Priyanka Rajan's portfolio website focusing on cancer biology, bioinformatics, and ML-based biomarker workflows.

Built with Tailwind CSS (via Play CDN), EB Garamond, and Inter fonts.

## Structure
* `index.html` - The core website page.
* `data.js` - Central content source (edit this file to update details, experience, education, links, etc.).
* `PRajan_resume.pdf` - Professional Resume.
* `PRajan_CV.pdf` - Professional CV.
* `avatar.jpg` - Profile Photo.

## Publishing to GitHub Pages
To publish updates, push files on the `main` branch to the GitHub repository:
```bash
git add .
git commit -m "update website content"
git push -u origin main
```
The page is configured to serve automatically at [priyan-rajan.github.io](https://priyan-rajan.github.io).
